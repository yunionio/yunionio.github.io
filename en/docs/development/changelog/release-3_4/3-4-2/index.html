Released at 2020-10-15 20:07:38

cloudpods​

Repo: https://github.com/yunionio/cloudpods

12 commits to cloudpods - v3.4.2 since this release.

Bug Fixes (8)​

  • allwo filter resource by with-meta and with-user-meta filter (ff2b7eb345, Qiu Jian)
  • support filter rds sku by provider (7b5d822373, Qu Xuan)
  • filter project role with system=true (8042b9430c, Qiu Jian)
  • filter role assignments by project domains id or name (d1cbaead09, Qiu Jian)
  • use new api (1768d1e7db, Qu Xuan)
  • support fake tempalte when searching template vm (c7d6bb7811, Rain)
  • 优化安全组规则同步 (d2d2934e80, Qu Xuan)
  • esxiagent: check whether regexp is nil (2076a75113, rainzm)

Features (3)​

  • add 'vlan_id' param when creating network (ff34e93862, rainzm)
  • change templateid as <providerId>/<uuid> in esxi (a891d1d876, rainzm)
  • esxiagent: keep data disks when cloning vm (5d0d6d960b, rainzm)

Others (1)​

  • fix:openstack lb 后端ip无法映射到主机的异常处理 (cf89e8a23a, lvyangyang)
